AI 윤리 탐험
중학생을 위한 3차시 자율 학습형 AI 윤리 웹앱입니다. 학생은 학교 구글 계정으로 로그인해 사전 퀴즈로 수준을 확인한 뒤, 자기 속도로 3개 차시를 학습하고 차시마다 퀴즈를 통과해 이수합니다. 교사(관리자·담임)는 학생별 진행 상황과 학급별 이수율을 한 화면에서 확인합니다.
서버: Google Apps Script (별도 서버·비용 없음)
데이터: 구글 스프레드시트 (학생 1명 = 1행)
로그인: 웹 앱을 학교 도메인 사용자만 쓸 수 있게 배포 → 접속한 구글 계정의 이메일로 학생·교사를 구분
파일
파일	역할
`Code.gs`	Apps Script 서버. 웹 화면 열기(`doGet`), 최초 설정(`setup`), 시트 읽기·쓰기, 화면에서 오는 요청 처리(`api`)
`Core.gs`	진행 규칙 모음. 장별 최소 학습 시간, 수준별 시작 장, 권한 확인, 학생·권한 관리, 명단 일괄 등록 해석. 서버와 화면(데모)이 같은 규칙을 함께 씀
`Index.html`	학생·교사 화면 전체(학습 내용, 퀴즈, 교사 대시보드). Apps Script 에서 그대로 쓰기 위해 앱 코드는 파일 안에 묶어(인코딩해) 넣어 두었습니다
학생 학습 흐름
로그인·본인 확인 — 로그인한 구글 계정과 이름·학급·학번을 보여 주고 "네, 제 계정이에요"를 눌러 시작합니다. 공용 컴퓨터에서 다른 친구 계정으로 기록되는 것을 막기 위한 단계입니다(계정 바꾸기 버튼 제공).
사전 퀴즈(6문항) — 점수에 따라 수준 상·중·하가 정해지고, 수준별로 각 차시를 몇 장부터 시작할지 달라집니다(기본: 상 5장, 중 3장, 하 1장부터). 건너뛴 장의 핵심은 "건너뛴 장, 이것만 알고 가요"로 요약해 보여 줍니다.
차시 학습(차시당 7장) — 각 장에서 정해진 시간이 지나야 다음 장으로 넘어갑니다. 시간은 서버 시계로 확인하므로 새로고침으로 건너뛸 수 없습니다. 영상 장은 시청 비율도 확인합니다.
차시 퀴즈(3문항) — 마지막 장까지 학습하면 퀴즈가 열립니다. 틀리면 다시 도전하고, 같은 문제를 여러 번 틀리면 해설이 공개됩니다. 3문항을 모두 맞히면 다음 차시가 열립니다.
이수 완료 — 3차시 퀴즈까지 통과하면 이수 처리되고 이수 일시가 기록됩니다.
학습 기록은 학생마다 스프레드시트 한 행에 저장되어, 다른 기기에서 다시 로그인해도 이어서 학습할 수 있습니다.

명단 양식
머리글: 학번 | 이름 | 이메일 | 학급
학급은 `1-3` 또는 `1학년 3반` 모두 됩니다. '학년'과 '반' 열이 따로 있어도 읽습니다.
이메일은 학생이 로그인할 학교 구글 계정입니다. 학번이 같으면 정보만 갱신하고 학습 기록은 유지합니다.
교사 계정 이메일은 학생으로 등록할 수 없습니다.

설치·배포
새 구글 스프레드시트를 만들고 [확장 프로그램] → [Apps Script] 를 엽니다.
편집기에 파일 3개를 만듭니다: `Code.gs`, `Core.gs`(스크립트 파일), `Index`(HTML 파일 — 이름은 `Index`). 이 저장소의 내용을 각각 붙여넣고 저장합니다.
편집기 위쪽에서 함수 `setup` 을 골라 실행하고 권한을 허용합니다.
→ 시트들이 만들어지고, 실행한 계정이 관리자로 등록됩니다.
[배포] → [새 배포] → 유형: 웹 앱
실행 사용자: 나(소유자) — 학생이 스프레드시트에 직접 접근하지 않아도 기록이 저장됩니다.
액세스 권한: (학교 도메인) 내 모든 사용자 — 학교 구글 계정으로만 들어오게 하고, 접속자 이메일로 학생을 구분합니다.
나온 웹 앱 주소(`https://script.google.com/macros/s/…/exec`)를 학생에게 안내합니다.
교사 화면 일괄 등록에서 학생 명단을, 권한·설정에서 담임 교사를 등록합니다.
(선택) 화면 확인용 샘플 학생 24명: 편집기에서 `addSampleStudents` 실행.
코드를 고친 뒤에는 [배포] → [배포 관리] → 편집(연필) → 버전: 새 버전으로 다시 배포해야 학생 화면에 반영됩니다.
데모 모드
`Index.html` 을 브라우저로 바로 열면 서버 없이 데모 모드로 동작합니다. 샘플 관리자·담임·학생 계정을 골라 화면을 둘러볼 수 있고, 기록은 그 브라우저에만 저장됩니다(스프레드시트 불러오기는 동작하지 않음).
Oh SSEM 과 함께 쓰기
정보 수업용 웹앱 Oh SSEM(https://ohssem.vercel.app)의 사이드바에 이 과정을 연결해 쓰고 있습니다.
Oh SSEM 교사 화면 → `✎ 편집` → 메뉴 `⋯` → 아래에 추가: 링크 → 이름 `AI 윤리`, 주소에 이 앱의 웹 앱 주소를 넣습니다.
학생이 Oh SSEM 에서 AI 윤리를 누르면 이 앱이 새 탭으로 열리고, 학교 구글 계정으로 로그인해 과정을 이수합니다.
이수 여부는 Oh SSEM 이 아니라 이 앱의 교사 화면(또는 '학생' 시트) 에서 확인합니다.
구글 로그인 화면은 다른 사이트 안에 끼워 넣을 수 없어서, Oh SSEM 화면 안이 아닌 새 탭으로 여는 방식을 씁니다. 새 탭에서는 Oh SSEM 의 고정·따라오기가 적용되지 않습니다.
알아 둘 점
학교 구글 계정(Google Workspace) 이 있어야 합니다. 개인 Gmail 로 배포하면 접속자 이메일을 확인할 수 없습니다.
등록되지 않은 계정으로 들어오면 "등록되지 않은 계정" 안내가 나옵니다. 학생 명단의 이메일을 확인하세요.
학생 이름·학번·이메일이 스프레드시트에 저장됩니다. 학교 개인정보 처리 기준에 맞게 공유 범위를 관리하고, 학기 후 필요 없는 기록은 지워 주세요.
여러 학생이 동시에 써도 기록이 섞이지 않도록 학생은 자기 행만 읽고 쓰며, 관리 작업은 잠금(Lock)을 걸고 처리합니다. Apps Script 실행 할당량이 있으므로 한 번에 아주 많은 인원(수백 명 동시 접속)은 피하는 것이 좋습니다.
